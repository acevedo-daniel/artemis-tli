# Cálculo de Energía Cinética Inicial

## Datos
- **Masa (m):** 26.000 kg
- **Velocidad (v):** 10.900 m/s

## Fórmula
Ec = 1/2(m*v**2)

## Sustitución de valores
Ec = 1/2(26.000 kg*(10.900m/s)**2)

## Resultado
Ec = 1.544.530 J

## Conclusión 
Se calculó la energía cinética del vehículo Orion al comenzar el viaje translunar mediante la fórmula clásica de energía cinética. Este resultado servirá de referencia inicial validada a mano para el equipo.
